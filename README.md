
# Lab 1 - Node.js and Express Server

## Aim
To create a basic Node.js HTTP server and an Express server.

## Technologies Used
- Node.js
- Express.js
- JavaScript

## Features
- Home route (`/`) displays a welcome message.
- About route (`/about`) displays student details.
- Time route (`/time`) displays the current date and time.
- Invalid routes return a 404 error.

## How to Run

1. Install dependencies:
   npm.cmd install

2. Start the Express server:
   node app.js

3. Open in your browser:
   http://localhost:3000

## Routes
- `/` - Welcome message
- `/about` - Student details
- `/time` - Current date and time
- Unknown routes - 404 Page Not Found
